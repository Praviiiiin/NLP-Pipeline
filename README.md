# NLP Text Preprocessing Pipeline (Tokenization, Stopword Removal, Stemming, Lemmatization)

## Project Overview

This project demonstrates a basic **Natural Language Processing (NLP) text preprocessing pipeline** using Python and NLTK. It processes a sample paragraph through multiple essential preprocessing steps required before applying Machine Learning models to textual data.

The goal of this project is to understand how raw text is transformed into structured and meaningful tokens for downstream NLP tasks.

## Features Implemented

The following preprocessing steps are performed:

* Tokenization (splitting text into words)
* Stopword Removal (removing common words like *is, the, and*)
* Stemming using Porter Stemmer
* Lemmatization using WordNet Lemmatizer

These steps help improve text quality for Machine Learning and NLP model training.

## Technologies Used

* Python
* NLTK (Natural Language Toolkit)
* NumPy
* Pandas
* Scikit-learn

## Workflow

The pipeline follows these steps:

1. Import required libraries
2. Download necessary NLP datasets
3. Input a custom paragraph
4. Perform tokenization
5. Remove stopwords
6. Apply stemming
7. Apply lemmatization
8. Display processed outputs at each stage

## Learning Outcome

Through this project, the following NLP concepts were implemented and understood:

* Text normalization techniques
* Difference between stemming and lemmatization
* Importance of stopword filtering
* Basic preprocessing pipeline for NLP-based Machine Learning models
